13. Middleware calls through HA APIM with a gateway key code-findings

04. API CONTRACT
Middleware calls through HA APIM with a gateway key
POST /api/sorter/auto-register
JSON
// request { "usid": "QECAA0032R", "sorterId": "QEH-SORTER-01", "hospital": "QEH", "hkid": null, "patientName": null } // response data { "status": "REGISTERED", "labCode": "CPS", "testCode": "LFT" }
Gateway headers
x-gateway-apikey and x-ha-hospcode.
Hospital sent skips the map
Sent: Map workbench and user only. Omitted: loesort_hosp.
Returned status, labCode, testCode
HTTP 200 is not Registered. Bin from status. labCode and testCode are LIS. 500 means retry.

Notes. Same hosts and headers as the GCRS-LIS API specification v1.0, but a new APIM product. Business failure codes sit on data.code, never as an HTTP 4xx from LIS.
