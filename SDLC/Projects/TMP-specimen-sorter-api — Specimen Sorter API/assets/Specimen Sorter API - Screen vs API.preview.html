11. USID is the request no. only when eligible compare

TEST GROUPING AND REQUEST NO.
USID is the request no. only when eligible
MANUAL
Screen groups, then assigns
· Tests are grouped before Register. Each group needs a request no. · USID can be the request no. when the screen says it is eligible. · Staff can tick Relabel. Multi-group, multi-specimen, suffix not 0, or force: no USID.
SORTER POST
Same grouping. No checkbox.
· Same Relabel rules, without a user tick. · One group, one specimen, suffix 0, not force: request no. = USID. · Else Relabel. No lab request. No invented number. No caller-assigned request no.
Relabel is its own status. Not Failure. Not Registered.

12. A missing map stops the POST compare

WARD AND DOCTOR MAPPING
A missing map stops the POST
MANUAL
Map, then popup
· Doctor, location, specialty, report dest, and report copy come from dictionary. · Unmapped codes block Register. · Staff can create a doctor when dictionary allows it.
SORTER POST

13. Print all after Registered, not before compare

WORKSHEET PRINTING
Print all after Registered, not before
MANUAL
Staff print after Register
· Staff can print GCRS, send-out, and SH worksheets after register. · If more than one worksheet, staff pick. · Labels can also print on the staff path.
SORTER POST
Print all, after the HTTP return
· Return REGISTERED first. Then print every worksheet Spec Ack would. No picker. · Send-out, Relabel, and Failure print nothing. No labels. · Late worksheet is allowed. Print fail is ALS. Status stays Registered.
