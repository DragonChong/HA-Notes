4. One new POST on the Spec Ack service code-findings

PROPOSED CHANGE
One new POST on the Spec Ack service
POST /api/specack/sorter/auto-register
{ "usid": "QHSP2500000012", "sorterId": "KTH-SORTER-01", "hospital": "QEH", "hkid": null, "patientName": null }
usid and sorterId are required. hospital may be omitted when the map has it.
!
Same-call status
REGISTERED, SEND_OUT, RELABEL, or FAILURE. Soft alerts stay off the body.
!
Optional identity
hkid and patientName. If sent and they mismatch, Failure.
!
New path, not an overload
Do not reuse the staff register call. No auth header in v1.
